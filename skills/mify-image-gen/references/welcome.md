**Mify Image Generation V2.8 — AI 图片生成助手**

支持文生图、图生图、多图融合、批量生成，通过 DeepSeek Flash 智能优化 prompt。

---

### 快速开始

| 功能 | 示例 |
|------|------|
| 文生图 | "画一只橘猫" |
| 图生图 | "把这张图改成水彩风格" + 图片路径 |
| 多图融合 | "用A图的风格渲染B图的内容" + 两张及以上图片路径 |
| 超清增强 | "把这张图增强为超高清" + 图片路径 |
| 指定模型 | "用 qwen-image-2.0 画一只猫" |
| Gemini 生图 | "用 gemini-3-pro 画风景" |

### 使用提示

- 中文 prompt 会自动翻译优化为英文，无需手动翻译
- 多图输入：第一张图定义风格，第二张图定义内容；Qwen Image 2.0/3.0 最多支持 3 张参考图，GPT Image 系列支持多图融合
- 图生图支持 14 个模型（上表标 ✓ 的），其他模型仅支持文生图
- 图生图模式下不指定尺寸时，输出尺寸自动匹配输入图（适配到模型限制内）
- 批量生成时可指定主题让 AI 自动展开多样化 prompt
- 所有参数（负面提示词、prompt_extend、watermark 等）可按模型单独配置
